## 开《森林之子》服务器，有三条绕不开的限制

先把这三条看完，再决定买哪档，能省掉一次退款流程。

**没有 Linux 原生服务端。** 《森林之子》的服务端只能跑 Windows，或者靠 Wine 做一层兼容。这意味着两件事：一是你不能买最便宜的那种纯 Linux 命令行 VPS 直接跑，要么选带 Windows 的机型，要么自己折腾 Wine 并且接受它带来的各种版本兼容问题；二是那些"一键部署 Linux 服务端"的教程，套到这款游戏上多半跑不通。雨云游戏云的机型默认给 Windows 系统和远程桌面，这条路对《森林之子》是必需的，省掉了自己装系统、激活授权的一圈事。

**内存至少 8G。** 这是硬门槛，不是"建议配置"。4G 内存的机器不是跑起来卡一点，是根本撑不住。雨云最便宜的两档 NAT 机型都给了 12G，刚好在这个门槛上方留了余量，够几个人玩，也够系统本身的开销。买之前不用纠结要不要加到 16G，先用 12G 跑，真觉得不够再在面板里加内存，比重买一台省事。

**游戏本身没有 GM 管理和详细参数体系。** 这一条最容易被忽略。很多人对"服主"的印象来自《我的世界》：装插件、刷物品、改规则、踢人封号、调几十项游戏参数。《森林之子》给不了这些。服务端能调的基本是开局模式、难度、少量倍率这类基础项，没有后台指令系统，也没有插件生态。你租到的机器更像一台 24 小时不关机的托管主机，把世界一直挂在那里等人进来，而不是一个可以随意摆弄的沙盒后台。想靠服务器实现"管理员发装备"这类玩法，这款游戏没有提供入口。

## 面板开服和自己搭，差在哪

**面板开服的流程**大体是这样：下单付款，等系统装好（十几分钟到半小时这个量级，晚高峰可能拖到一小时），进控制台左侧的"版本配置"设服务器名称、模式、难度这些基础信息，再到"游戏配置"里调游戏内参数、倍率、时间流速。改完如果服务器正在运行，需要重启一次才生效，不重启等于没改。

这条路的好处是你不用碰命令行。代价是面板能调的东西就是游戏本身开放的那些，而《森林之子》开放的并不多，所以面板的价值主要在"装好就能用"，不在"能调很多"。

**自己用 SteamCMD 搭**，本质是租一台带 Windows 的 VPS，把服务端文件拉下来手动跑。需要自己处理的事有这么几件：端口要在安全组或防火墙里放行，协议别选错，选错了客户端怎么都连不上；服务端进程要挂后台常驻，用 Windows 服务或者计划任务把它守住，不然远程桌面一断、机器一重启，服就没了；游戏更新之后要停服、重新拉一遍服务端文件，不然版本对不上。这几件事跟具体哪款游戏无关，是自建服务端的通用功课。

自建适合一种人：你本来就打算在这台机器上折腾别的东西，或者需要一些面板给不了的定制。如果只是想和朋友安安静静玩一个世界，面板省下来的时间比省下来的钱值钱。

需要提醒的是，雨云的面板是否已经提供《森林之子》的预装模板，下单前最好直接问客服确认。有模板，开通就能进游戏；没有模板，你拿到手的是一台干净的 Windows 机器，得自己把服务端放上去。这个差别决定了你是十分钟能玩上，还是要花一晚上。

## 两个最容易翻车的点：存档和版本

**下线前必须在睡袋或帐篷里存档，否则存档会丢失。** 这条不是服务器的问题，是游戏机制，但它造成的损失比任何配置不足都大。建了三天的基地、砍了一整片森林、搬回来的物资，因为退出方式不对归零，这种事在《森林之子》的联机里发生过太多次。养成习惯：退出前先回营地，进睡袋或帐篷存一次，再关游戏。服主这边也一样，别在有人没存档的时候直接重启服务器。

**客户端和服务端版本要一致。** 游戏更新之后，老版本客户端连不上新版本服务端，反过来也一样。搜不到服务器、一直卡在连接中，先检查这一项，比查端口快。至于具体是哪个版本号，以你服务器面板上显示的为准，不用记。

## 客户端怎么进服，搜不到怎么办

进服路径不复杂：先在面板的版本配置里复制你自己设的服务器名称，打开游戏选"多人游戏"，再选"专用服务器"，把名称输进去搜索加入。

搜不到的时候按这个顺序排查，前面几步能解决大部分情况：

1. 改完配置之后有没有重启服务器。改参数不重启是最常见的"明明设了却没反应"。
2. 端口映射的协议对不对。《森林之子》走 UDP，映射时选成 TCP 就连不上；从外部端口进来的号，客户端也要填同一个号，内外不一致同样连不上。
3. 防火墙和安全组有没有放行对应端口。控制台里放行了、Windows 自带的防火墙没放行，一样是白搭。
4. 客户端版本和服务端版本对不对得上。
